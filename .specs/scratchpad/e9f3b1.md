## Stage 2: Reference Result
A high-quality procedural kinematics controller must:
1. Drive all positional, rotational, and scaling transforms using delta-time dt.
2. Formulate vertical levitation with incommensurate frequencies (1.173 and 0.781 rad/s).
3. Apply asymmetric audio envelope smoothing (fast attack ~15ms, smooth release ~120ms).
4. Strictly clamp audio scale pulse to <= 1.04 (< 4%).
5. Track cursor with deadzone (0.08) and clamp rotation angles to <= 0.21 rad (~12 deg).
6. Provide immediate and dynamic support for reduced motion preference.
7. Return decoupled transform snapshots in getTransform() to prevent external mutation.
8. Safely handle edge case inputs (negative/zero dt, null/undefined cursor).
