## Stage 2: Reference Result
A high-quality audio synchronization engine must:
1. Provide instant barge-in interruption via unified AbortController.
2. Ensure strict mute guarantees: zero amplitude, zero audio output, immediate interruption.
3. Compute frequency-based vocal amplitude from Web Audio AnalyserNode during buffer playback.
4. Provide procedural envelope simulation during Web Speech API synthesis without clobbering.
5. Isolate faults cleanly: missing hardware or unsupported APIs must never throw or crash caller.
6. Support universal exports across Node.js, Window, and globalThis.
